# Dashboard de Vendas

Dashboard criado em Excel para análise e visualização de desempenho de vendas.

## 📊 Funcionalidades
- Total de vendas
- Vendas por produto
- Vendas por região e vendedor
- Filtros interativos

## 📂 Arquivos
- `dashboard_vendas.xlsx`: Dashboard final em Excel
- `base.xlsx`: Base de dados bruta utilizada

## 🔧 Ferramentas
- Microsoft Excel
- Tabelas e gráficos dinâmicos
